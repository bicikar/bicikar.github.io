# Лендинг «В кругу тех, кто строит сообщества»

Статический одностраничный сайт на HTML, CSS и JavaScript. Сборка и npm не требуются.

## Структура

- `index.html` — содержание и секции страницы;
- `styles.css` — фирменные шрифты, цвета и адаптивная вёрстка;
- `script.js` — список гостей, переключение карточек с фото/без фото и отправка формы;
- `assets/` — облегчённые копии фирменной графики для быстрой загрузки;
- `resources/` — переданные шрифты и графические элементы;
- `_headers` — запрет индексации и защитные заголовки для Cloudflare Pages/Netlify.

## Карточки гостей

Тестовые данные находятся в начале `script.js` в массиве `guests`.

Чтобы включить вариант с фотографиями у всех гостей:

```js
const SHOW_GUEST_PHOTOS = true;
```

В каждом объекте гостя заполните `name`, `role`, `telegram` и `photo`.

## Обратная связь

Форма визуально готова, но намеренно не отправляет данные, пока не выбран получатель.
После создания endpoint вставьте его в атрибут `data-endpoint` формы в `index.html`:

```html
<form id="feedbackForm" data-endpoint="https://адрес-обработчика">
```

Подойдут Formspree, Netlify Forms, Cloudflare Worker или собственный обработчик.

## Локальный просмотр

Откройте папку проекта в терминале и запустите:

```bash
python3 -m http.server 8000
```

После этого сайт будет доступен по адресу `http://localhost:8000`.

## Хостинг и приватность

Страница содержит `noindex`, но это не ограничение доступа. Любой человек, получивший
URL, сможет открыть страницу и переслать её. Для реальных личных контактов предпочтителен
хостинг с паролем или авторизацией, например Cloudflare Pages вместе с Cloudflare Access.

GitHub Pages подходит только в том случае, если публичный доступ по прямой ссылке приемлем.

## Публикация из этого репозитория

Репозиторий `bicikar.github.io` настроен как пользовательский сайт GitHub Pages. После
проверки изменений достаточно зафиксировать их в ветке `main` и отправить на GitHub.
Главная страница должна лежать в корне репозитория под именем `index.html` — текущая
структура уже соответствует этому требованию.

Файл `.nojekyll` отключает дополнительную обработку Jekyll: GitHub Pages будет отдавать
HTML, CSS, JavaScript, локальные шрифты и изображения без этапа сборки.
